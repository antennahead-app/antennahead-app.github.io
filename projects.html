Things to do with AntennaHead

Step-by-step projects that use AntennaHead and ControlBooth for something useful. Pick one from the list.

1. Set up the AntennaHead workspace

Use the antennahead-workspace project on GitHub to create one umbrella folder with the whole suite of AntennaHead projects, ready to build in Xcode.

2. An aviation-band scanner for your local airport

Find your airport’s frequencies, save them as Favorites, group them in a Category, and set the squelch with the Now Playing page.

3. Use a shell script with rtl_fm as an audio source

Write your own rtl_fm script and run it as the first stage of a ControlBooth pipeline.
